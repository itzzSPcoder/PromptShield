1. Project Objectives

The primary objective of PromptShield-AI is to systematically identify, quantify, and mitigate Large Language Model (LLM) vulnerabilities—specifically prompt injections, persona jailbreaks, and confidential system prompt leakage—using principled in-context prompt engineering rather than slow, costly external guardrail models.

  • Automate Vulnerability Auditing: Standardize prompt testing across 6 OWASP LLM01/LLM02 threat classes.
  • Enforce Code-Data Separation: Isolate untrusted user input from developer system instructions using structural XML delimiters.
  • Guarantee Credential Secrecy: Invalidate canary token exfiltration and prompt repetition attempts through explicit constitutional invariants.
  • Preserve Operational Utility: Eliminate false refusals on genuine customer inquiries via Dual-Intent Cognitive Gating.
  • Automated Defense Synthesis: Provide a 1-click meta-compiler to generate production-hardened prompts dynamically.

2. Scope of the Project

The scope encompasses production conversational LLM applications such as transactional banking assistants and code review bots. The system audits 6 major attack categories:

  • Direct Instruction Override: Imperative jailbreaks and universal adversarial suffixes.
  • Persona Hijacking: Maintenance mode pretexts, DebugBot impersonation, and unconstrained personas.
  • System Prompt & Canary Leakage: Verbatim repetition probes and canary token extraction.
  • Delimiter Hijacking: Closing XML/JSON tags and Markdown boundary escapes.
  • Encoding & Obfuscation: Base64 encoded payloads, ROT13 ciphers, and leetspeak substitutions.
  • Indirect Injection: Simulated RAG document context poisoning.

  • Interactive Defense Portal: Full-stack FastAPI application deployed live globally on Cloudflare Workers featuring real-time attack execution and instant 1-click prompt hardening.
